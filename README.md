# PrintStyle Academy — v104 UI Cleanup

Актуальная тестовая сборка PrintStyle Academy после этапа продуктовой и визуальной полировки.

## В составе
- SPA с hash-навигацией;
- курсы и маршруты обучения;
- личный кабинет и прогресс;
- база знаний;
- диагностика и диагностический тренажёр;
- матрица компетенций;
- глобальный поиск;
- локальные учебные SVG и логотип;
- демонстрационные авторизация, прогресс, сертификаты и админ-раздел на localStorage.

## Важно
- Карта знаний удалена из пользовательского интерфейса и из исходного кода.
- Backend, регистрация и модель хранения данных в этом этапе не менялись.
- Диагностика и отдельные карточки дефектов требуют авторизации.
- Материалы по конкретным настройкам оборудования остаются учебными и не заменяют локальные инструкции производства.

## Запуск
1. Распаковать ZIP.
2. Запустить `START.bat`.
3. Либо поднять `server.ps1` вручную.

## QA
- `node --check app.js` — должен проходить без ошибок.
- Проверены локальные ссылки на `assets/...`.
- Удалены пустые служебные каталоги и оставшийся код удалённой карты знаний.
- Навигация в шапке адаптирована так, чтобы на desktop-полосу помещался весь основной набор пунктов; на узких экранах включается меню.

## v108-public-foundation
Public pages were reworked from the v107 baseline around a profession-first funnel: profession understanding -> reasons to consider the field -> audience routes -> learning proof -> course conversion. Auth, progress, diagnostics and backend/demo architecture were not changed.
